# 자율적 내부점검 딸깍

농협 통장거래내역과 K-에듀파인 엑셀 자료를 한꺼번에 업로드하면 자료 종류를 자동으로 판별하고 장부잔액과 통장잔액을 대조하는 웹 도구입니다.

## 1차 MVP

- `.xls`, `.xlsx` 여러 파일 동시 업로드
- 농협 입출금거래내역 자동 인식
- 학교회계 현금출납부 자동 인식
- 세입세출외현금 현금출납부 자동 인식
- 세입세출외현금 출납계산서 자동 인식
- 계좌번호 사전등록 없이 **장부 최종잔액과 통장 최종잔액을 비교해 학교회계/세외 통장을 자동 매칭**
- `NH비씨대금` / `NHBC기업카드` 거래로 법인카드 통장 자동 식별
- 법인카드 결제일별 결제금액 및 결제 후 잔액 0원 확인
- 통장잔액 대조 결과 Excel 다운로드

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 입력자료 권장 구성

- 농협 학교회계 통장 거래내역 1개
- 농협 세입세출외현금 통장 거래내역 1개
- 농협 법인카드 통장 월 전체 거래내역 1개
- K-에듀파인 학교회계 현금출납부 1개
- K-에듀파인 세입세출외현금 현금출납부 1개
- K-에듀파인 세입세출외현금 출납계산서 1개

파일명은 변경하지 않아도 되며 파일 내용으로 종류를 판별합니다.

## 출력 로드맵

최종 목표는 다음 3종입니다.

1. 자율적 내부점검 보고서 PDF
2. 통장잔액 대조 Excel
3. 제출용 통장사본 정리 PDF

현재 1차 MVP는 2번과 핵심 대조 로직을 우선 구현했습니다. 1번과 3번은 기존 Excel VBA 출력 양식을 기준으로 재현합니다.

## 보안

실제 계좌번호, 기관명, 거래내역이 포함된 예시 업무파일은 저장소에 포함하지 않습니다. `.gitignore`에서 Excel/PDF 업무자료를 기본 제외합니다.
