# 자율적 내부점검 딸깍

농협 통장거래내역과 K-에듀파인 자료를 한꺼번에 넣으면 파일 종류를 자동으로 판별하고, 점검 기준일의 잔액을 대조해 **자율적 내부점검 결과 3종**을 생성하는 Streamlit 웹 도구입니다.

## 현재 구현 범위

### 입력
- 농협 입출금거래내역 `.xls` / `.xlsx`
- K-에듀파인 학교회계 현금출납부 `.xlsx` 또는 PDF
- K-에듀파인 세입세출외현금 현금출납부 `.xlsx` 또는 PDF
- K-에듀파인 세입세출외현금 출납계산서 `.xlsx` 또는 PDF
- 법인카드는 기존 12일/27일 분리파일 또는 월 전체 거래내역 1개 모두 지원하도록 설계

### 자동 판별/점검 원칙
- **파일명은 판별에 사용하지 않음**
- 학교회계/세외 현금출납부는 문서 내부의 열 구조로 구분
- 학교회계/세외 통장은 금액의 크고 작음으로 추정하지 않고 **점검 기준일 장부잔액과 통장 거래후잔액의 정확한 일치**로 매칭
- 한 계좌만 정확히 매칭되고 비카드 계좌가 하나 남은 경우에는 계좌 구성으로 안전하게 보조 판별
- 농협 `현재통화잔액`은 다운로드 시점 잔액이므로 월말 점검값으로 사용하지 않음
- 법인카드는 `NH비씨대금` / `NHBC기업카드` 거래를 찾아 결제 직후 잔액 0원을 확인
- 학교회계 정기예금이 있으면 `통장잔액 + 정기예금 = 장부잔액`으로 점검

## 출력 3종
1. **자율적 내부점검표 PDF**
   - 현금출납부-통장잔액 일치 여부 자동 표시
   - 신용카드대금 결제 후 잔액 0원 여부 자동 표시
   - 나머지 수기 점검 항목은 웹에서 선택 입력
2. **회계통장 잔액 현황 Excel**
   - 제공된 기존 결과 양식에 맞춘 학교회계/세외/법인카드 3개 구역
3. **통장잔액 정리 PDF**
   - 학교회계 → 세입세출외현금 → 법인카드 결제일 순으로 자동 정리
   - 원본 거래내역을 내부점검용 정리본으로 명확히 표시

세 파일은 각각 받을 수도 있고 ZIP으로 한 번에 받을 수도 있습니다.

## UI
딸깍 웹 도구 표준에 맞춰 흰색 카드, 블루 포인트, 단계형 흐름으로 구성했습니다.

`자료 업로드 → 자동 판별 → 보고서 설정 → 자율적 내부점검 실행 → 결과 3종 다운로드`

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 테스트

```bash
python -m unittest discover -s tests -v
```

현재 자동화 핵심 로직, 문서 구조 판별, 기준일 거래후잔액 사용, 정기예금 보조매칭, Excel/PDF 출력 생성 테스트가 포함되어 있습니다.

실제 업무 샘플은 개인정보와 금융정보가 포함되므로 저장소에 올리지 않습니다. 로컬에 샘플을 둔 경우 아래 검증 도구로 K-에듀파인 Excel/PDF 파서를 확인할 수 있습니다.

```bash
python scripts/validate_samples.py /path/to/sample-folder
```

## 보안

- 실제 계좌번호, 기관명, 거래내역이 포함된 샘플 파일은 GitHub에 포함하지 않습니다.
- `.gitignore`에서 `.xls`, `.xlsx`, `.xlsb`, `.pdf` 업무자료를 기본 제외합니다.
- 저장소에는 코드와 합성 테스트만 포함합니다.
